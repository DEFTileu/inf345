# План разработки

Игра: Faculty Wars (пейнтбол) + Prop Hunt в low-poly корпусе SDU. Почему так — в `IDEAS.md`.
Стек: Three.js + Vite + TypeScript + Rapier, мультиплеер через PartyKit или Colyseus. Подробнее — в `RESEARCH.md`.

Сроки примерные. Под «сессией» имеется в виду одна сессия Claude Code на одну задачу.

## Этап 0. Подготовка (1–3 дня, в основном без кода)

Это делаете вы, ИИ тут не поможет:
- [ ] Выбрать идею и название.
- [ ] Собрать референсы корпуса SDU в `references/`: фото коридоров, аудиторий, столовой, библиотеки, входа. Планы этажей (хотя бы схема от руки). Короткие видео прохода по коридору.
- [ ] Выбрать 1 локацию для первой карты, например один этаж главного корпуса.
- [ ] Решить, нужны ли платные генераторы (Tripo, ElevenLabs, Gemini). Можно начать без них, на бесплатных CC0-ассетах.
- [ ] Найти 3–5 друзей-тестеров.

## Этап 1. Прототип: бегаю и стреляю (1–2 недели)

Цель: одиночная игра в браузере, которую не стыдно показать другу.
- [ ] Заготовка Vite + TS + Three.js (скилл `threejs-gameplay-systems`, у него есть шаблон).
- [ ] Дизайн-бриф и основной цикл игры в `docs/DESIGN.md`.
- [ ] Блок-аут карты: коридор, 2–3 аудитории, лестница. Простые блоки по планам из `references/`.
- [ ] Движение от первого лица: WASD + мышь (pointer lock), прыжок, коллизии (Rapier).
- [ ] Пейнтбол-ружьё: выстрел, полёт шарика, пятно краски на стене, отдача, звук.
- [ ] Боты-мишени или простые боты, которые бегают и стреляют в ответ.
- [ ] HUD: прицел, патроны, счёт, экран победы и поражения.
- [ ] Управление на телефоне: два джойстика (можно позже, но заложить в архитектуру).
- [ ] Деплой на GitHub Pages или Cloudflare Pages. Получаем ссылку.
- [ ] Playwright: скриншот, бот-плейтест, проверка мобильного экрана (скилл `threejs-qa-release`).

Готово, когда: друг открывает ссылку на ноутбуке и сразу понимает, что делать.

## Этап 2. Мультиплеер (1–2 недели)

- [ ] Выбрать сервер: PartyKit (есть скилл `add-multiplayer`) или Colyseus. Проверить цены и бесплатные лимиты.
- [ ] Комнаты по ссылке: «Создать комнату» → ссылка → друзья заходят.
- [ ] Синхронизация позиций, выстрелов, попаданий. Сервер решает, кто в кого попал (защита от читов).
- [ ] Командный бой 4×4, выбор факультета, таблица счёта.
- [ ] Тест с 8 реальными игроками на разных устройствах.

## Этап 3. Внешний вид и атмосфера (1–2 недели, можно параллельно с этапом 2)

- [ ] Единый арт-стиль: low-poly, цвета SDU, мультяшные персонажи.
- [ ] Узнаваемые места: вход, столовая, библиотека, лестничный пролёт, двор.
- [ ] Модели: CC0-паки (Kenney, Quaternius, Poly Pizza) + генерация узнаваемых предметов SDU (скилл `threejs-3d-generator`, если есть ключ Tripo).
- [ ] Звук: шаги, выстрелы, попадания, музыка меню (скилл `game-audio` без ключей или `threejs-audio-generator`).
- [ ] Меню, настройки, языки: қазақша / русский / English.
- [ ] Производительность: 60 FPS на среднем ноутбуке, нормально на телефоне (скиллы `threejs-perf`, `threejs-debug-profiler`).

## Этап 4. Второй режим: Prop Hunt (1–2 недели)

- [ ] Список предметов, в которые можно превращаться (20–40 штук).
- [ ] Механика превращения, поворот предмета, «свист» прячущегося раз в N секунд.
- [ ] Ищущий теряет очки за выстрел по пустому предмету.
- [ ] Раунды 3–5 минут, смена ролей.

## Этап 5. Запуск в SDU

- [ ] Закрытый тест с 20–30 студентами, собрать фидбек.
- [ ] Рейтинг факультетов на сайте игры (нужно простое хранилище на сервере).
- [ ] Короткие видео для TikTok / Reels / YouTube Shorts: смешные моменты из Prop Hunt, ролик «наш корпус в игре».
- [ ] Распространение: чаты потоков в Telegram и WhatsApp, студсовет, gamedev- и киберспорт-клубы SDU.
- [ ] Турнир факультетов с призом. Это самый сильный повод играть.
- [ ] Позже: Telegram Mini App, SDUGuessr как тизер, сезонные ивенты.

## Как работать с Claude Code

1. Открывайте сессию в репозитории. Скиллы из `SDU-Shooter/.claude/skills/` подключаются автоматически для файлов в этой папке.
2. Одна сессия — одна задача из чеклиста выше. В конце сессии агент отмечает пункт и обновляет `NOTES.md`.
3. Агент должен показывать доказательства: скриншот или результат Playwright, а не просто «готово».
4. API-ключи (`TRIPO_API_KEY`, `GEMINI_API_KEY`, `ELEVENLABS_API_KEY`) — только в переменных окружения, никогда в коде.
5. Если что-то сломалось — откатиться к последнему рабочему коммиту, а не чинить поверх.

### Первый промпт для этапа 1

> Используй скилл threejs-game-director. Сделай в папке SDU-Shooter первый играбельный прототип браузерного пейнтбол-шутера от первого лица по docs/IDEAS.md (идея 1) и docs/PLAN.md (этап 1). Стиль low-poly, мультяшный, без реалистичного оружия. Карта: один коридор корпуса университета с 3 аудиториями и лестницей, пока из простых блоков. Нужны WASD + мышь, прыжок, пейнтбол-ружьё с пятнами краски, 5 простых ботов, HUD и экран победы. Сначала напиши docs/DESIGN.md, потом код. Проверь игру через Playwright и покажи скриншоты. Коммить по шагам.
